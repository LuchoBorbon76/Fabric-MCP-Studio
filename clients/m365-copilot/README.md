# Microsoft 365 Copilot (Teams, Outlook, Copilot app)

Microsoft 365 Copilot reaches the demo through an agent built in Copilot Studio.

1. Build the agent in [Copilot Studio](../copilot-studio/README.md) with the Fabric IQ and Ontology MCP tools.
2. **Channels** → enable **Teams and Microsoft 365 Copilot** → publish.
3. Share or submit the agent for admin approval, according to your tenant's agent policies.
4. In Teams or the Microsoft 365 Copilot app, @-mention the agent and ask:
   *"How did same-store sales do this year, and why is total growth different?"*

Talk track for the finale: the same governed answer appears in VS Code, Copilot CLI and Teams because every client
reads the same semantic model and ontology through MCP, as the signed-in user.

Licensing: users need Microsoft 365 Copilot (or Copilot Studio messages for unlicensed users, per your agreement)
plus access to the Fabric items. Fabric RLS/OLS still apply.
