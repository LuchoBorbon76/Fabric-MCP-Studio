Setup

1. Get the kit and check prerequisites

git clone <your-copy-of-this-repo> fabric-mcp-demo cd fabric-mcp-demo .\scripts\prereq-check.ps1 -CheckFabric

Needs Node.js LTS, Git, Azure CLI (az login). Clone outside OneDrive-synced folders.

2. Connect your AI client

3. Verify connections

Use the fabric-demo-verify skill to check my MCP connections.

Expect ✅ for fabric-core, fabric-local, powerbi-authoring and fabric-iq.

4. Business users: install the Teams agent

Adds Contoso Retail Analyst to Microsoft 365 Copilot, Teams and Outlook in your tenant. Creates an Entra app with read-only, delegated Power BI permissions.

.\scripts\install-teams-agent.ps1 -DryRun # preview, no changes .\scripts\install-teams-agent.ps1 # install for you .\scripts\install-teams-agent.ps1 -Publish # submit for org-wide rollout

Needs Microsoft 365 Copilot and permission to upload custom apps. After act 4 add -IncludeOntology.

Plan B and reset

.\scripts\deploy-fabric.ps1 # lakehouse + tables without the agent .\scripts\deploy-ontology.ps1 # deploy ontology/retail TMDL .\scripts\reset.ps1 # delete what the demo created
